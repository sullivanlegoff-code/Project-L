# Version à essayer sous Windows

`prairie-lapins-visuel-v4.zip` contient le projet complet de la passe visuelle : sources, 369 tests validés, documentation, build et captures avant/après. L'archive historique habitats du dépôt reste conservée.

Sur GitHub, ouvrir le fichier ZIP dans cette branche puis utiliser **Download raw file / Télécharger le fichier brut**. Extraire dans un nouveau dossier ; suivre le README inclus pour démarrer sur le port 5175, séparément de la session existante sur 5173.

Sauvegardes v4 et règles du jeu inchangées. Les scénarios sont à importer volontairement en mode test uniquement.
